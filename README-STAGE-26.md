# Этап 26 — Global Game Data + Localized Editorial Content

Патч рассчитан на рабочую версию после Этапа 25. Распаковать в корень `seo-review-platform`, с заменой совпадающих файлов.

## Изменения
- `src/content/games/*.json`: единые числовые характеристики, независимые от языка.
- `src/content/locales/en/games/*.js`: существующие английские редакционные тексты, рейтинги и SEO-поля (без дублирования `facts`).
- `src/_data/games.js`: объединяет факты и английский контент, сохраняя интерфейс существующих Nunjucks-шаблонов.
- `scripts/check-games.mjs`: базовая проверка схемы; `npm run check:games`.
- `package.json`: новая команда проверки.

**Важно:** старые `src/content/en/games/*.js` останутся на диске после распаковки, но новый загрузчик их больше не использует. Удалять их можно после успешной сборки и проверки Git diff; новые файлы уже содержат редакционные тексты. Не редактируйте старые файлы после установки.

## Команды
```powershell
npm run check:locales
npm run check:games
npm run build
npm run dev
```

Проверьте `/en/games/sweet-bonanza/` и `/en/games/the-big-dog-house/`, особенно таблицу характеристик, рейтинг и SEO-теги.

## Ограничения
- Значения из существующего проекта перенесены **как есть**; они не верифицированы по официальным источникам (`sourceStatus: legacy-unverified`).
- Данные о RTP могут различаться между версиями игры и операторами; позже введём variant/market overrides и provenance.
- Немецкие и испанские редакционные файлы пока не созданы; новых страниц не публикуем.
- Это подготовка схемы, **не парсер** и не генератор обзоров.
