## Proposed page copy (original English draft)

### Sweet Bonanza: what is the original game?

Sweet Bonanza is a candy-and-fruit-themed slot developed by Pragmatic Play. The company announced the original title in June 2019. This overview focuses on that game rather than the later titles carrying the Sweet Bonanza name.

The original game uses a six-column, five-row arrangement. Instead of evaluating only fixed paylines, it can award wins when enough matching symbols appear in different positions on the grid. The symbols then tumble: a winning group is removed and replacement symbols enter the layout. A single paid round can therefore contain more than one sequence of symbol evaluations.

### How the matching-symbol and tumble system works

According to the producer's current description of Sweet Bonanza, a prize can be awarded when at least eight matching symbols appear anywhere in the grid. The provider describes winning groups in the range of eight to twelve or more matching symbols.

Tumbles change the visible arrangement after a win, which can produce another evaluation before the same round ends. This is a description of the game mechanic, not a claim that any particular outcome is likely or guaranteed. The exact award for each symbol group depends on the applicable paytable.

### What happens in the free-spins feature?

The developer describes a bonus feature triggered by scatter symbols, with ten free spins in the base description of the original game. During that feature, special multiplier symbols can appear. The developer's game overview gives multiplier values from 2× to 100×, with displayed multiplier values combined at the end of the applicable tumble sequence.

These free spins are **an in-game feature**, not a casino welcome promotion, a free-spins offer or an affiliate incentive. Feature behavior should be confirmed against the rules shown for the actual game version before final publication.

### RTP, volatility and different game configurations

RTP is a theoretical long-run return expressed as a percentage of total stakes across many plays. It does not predict the outcome of an individual spin or a short session. A game can also have different mathematical configurations depending on the version supplied by the operator.

For this original-game review, **we are not publishing a single fixed RTP or volatility rating yet**. The materials currently collected for the project do not establish the exact applicable rules and mathematical configuration to a sufficient standard. The operator's help or rules panel, when available, is the appropriate place to identify the version being offered.

### What about the advertised maximum win?

The producer's 2019 announcement describes a potential maximum win, but the legacy facts stored in this project carry a different figure. Those figures should not be treated as interchangeable, and neither is presented here as a verified maximum for all versions. The exact edition and stake basis must be reconciled against the corresponding official rules before publication.

### What readers should check

Before relying on numerical game information, confirm that a page refers to the same Sweet Bonanza edition shown in the operator's game rules. Check the paytable, feature explanations and any disclosed RTP or configuration information. Availability and local restrictions are separate matters; this article is not a statement that the game is available or permitted in any particular country.

## Short FAQ draft

**Who developed Sweet Bonanza?** Pragmatic Play identifies itself as the developer of the original title in its 2019 announcement and official product page.

**Does it use traditional paylines?** The official product page describes winning groups of matching symbols occurring anywhere on the grid, rather than wins limited to a small set of fixed payline patterns.

**Does the game have free spins?** Yes, the producer describes an in-game free-spins feature activated by scatter symbols. This is not a promotional offer.

**What is the precise RTP?** We have not approved an edition-specific RTP for this article. The RTP shown in the rules of the relevant game configuration should be checked before quoting a number.

**Are the later Sweet Bonanza versions the same game?** No. This page is scoped to the original title, not later branded sequels or variations; their rules and mathematical limits cannot be copied onto it.
